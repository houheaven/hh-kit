# hh-changeset-helper

## 何时使用

当满足以下**任一**条件时启用本 Skill：

1. 用户 query 中包含 `.changeset/*.md` 路径引用。
2. 文件名符合 changeset CLI 生成的三段式格式：`<形容词>-<名词>-<动词>.md`（例如 `funny-moments-build.md`、`dark-guests-look.md`、`tidy-pens-remain.md`）。
3. 文件正文仅包含 frontmatter 和一行占位内容（例如包名简写、随手记的关键词），未展开真实变更说明。
4. 用户明确要求「补全」「补充」「完善」「写一下」changeset 内容。

## 目标

将占位的 changeset 文件补全为规范的变更说明，供 `pnpm changeset version` / `changeset version` 汇总到 CHANGELOG。

## 输出格式规范

### frontmatter

保留原有 frontmatter，包含目标包名与语义化版本级别（`major` / `minor` / `patch`）：

```
---
"<package-name>": patch
---
```

### 正文结构

1. **首行**：一句话概括本次变更的主题，以中文句号结尾。
2. **空行**。
3. **变更列表**：使用无序列表（`-`）逐条列出变更点，每条不超过 30 个字，聚焦「做了什么 + 面向用户的价值」，不写实现细节（例如具体参数名、内部函数）。

### 首次发布模板

当 changeset 描述的是包的首次发布时，采用以下结构：

```
---
"<package-name>": patch
---

首次发布 `<package-name>`。

- 新增 `<feature>`：<一句话功能描述>。
- <其他核心能力点>。
```

### 常规迭代模板

```
---
"<package-name>": patch
---

<本次变更主题的一句话概括>。

- <变更点一>。
- <变更点二>。
```

## 硬性约束

### 内容层面

1. **单包原则**：每个 changeset 文件只针对 frontmatter 中列出的包，禁止在正文中提及其他包。
2. **面向用户**：只描述用户可感知的能力变化，不描述内部重构、CI 调整、目录迁移。
3. **克制粒度**：新增/变更内容只写「名称 + 定位」，不列举 props、事件、方法、字段等 API 细节。
4. **尊重原命名**：引用包名、组件名、字段名时使用反引号包裹，并保持项目原有大小写与前缀风格，不做首字母大写等自动转换。

### 格式层面

1. **标点符号**：正文中的标点必须使用中文标点符号，禁止使用英文标点。
   - 逗号使用「，」不使用「,」
   - 冒号使用「：」不使用「:」
   - 句号使用「。」不使用「.」
   - 顿号使用「、」不使用「/」
   - 分号使用「；」不使用「;」
   - 感叹号使用「！」不使用「!」
   - 问号使用「？」不使用「?」
   - 括号使用「（）」不使用「()」
   - **例外**：反引号内的代码标识符保持原样；链接、路径、frontmatter 中的英文标点保持原样。
2. **中英混排**：中文与英文单词、数字之间保留一个空格（例如「输出 ESM 与 CJS 双格式」而非「输出ESM与CJS双格式」）。
3. **frontmatter**：保持双引号包裹包名与 `---` 分隔符不变。

## 触发示例

### 示例：用户 query

> `.changeset/dark-guests-look.md` 补全信息

## 反面示例

以下写法**禁止**出现：

```
- 新增 `Dialog` 组件, 支持 `open` + `onOpenChange` 受控模式, 支持遮罩点击、ESC 关闭。
```

问题：
- 使用了英文逗号 `,`
- 暴露了 API 细节 `open` / `onOpenChange`
- 变更点过长

正确写法：

```
- 新增 `Dialog` 组件：轻量弹窗组件，适用于确认、提示等场景。
```

## 交付流程

1. 读取用户提到的 changeset 文件，确认 frontmatter 中的目标包名与版本级别。
2. 结合近期 commit、README、其他 changeset 判断本次变更主题。
3. 按上述模板与硬性约束生成新内容。
4. 使用文件写入工具覆写整个文件（changeset 文件通常仅 5~15 行，覆写比逐行编辑更清晰）。
5. 输出结果告知用户变更点条目数与是否含首次发布标记。

# @houheaven/kit-vue2

## 0.0.1

### Patch Changes

- 首次发布 `@houheaven/kit-vue2`。
  
  - 新增 `hh-header` 组件：展示站点标题与路由副标题的页头组件,并提供更多插件入口。
  - 新增 `hh-grids` 组件：响应式栅格布局,支持按手机/平板/电脑等屏幕宽度分别配置列数。
  - 新增 `hh-menu` 组件：基于 `hh-grids` 的分组导航菜单,支持外链、HTML 与路由跳转三种条目类型。
  - 支持子路径导出,可按需引用单个组件。
  - 消费方引入组件时无需手动导入样式文件。
  - 同时输出 ESM 与 CJS 双格式产物,并附带完整 TypeScript 类型声明。
